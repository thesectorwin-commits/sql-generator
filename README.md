# Генератор SQL-запросов

Сайт, который превращает вопрос на обычном языке в SQL-запрос (PostgreSQL) по описанию ваших таблиц.

- `index.html`, `app.js` — страница. Схема таблиц и история хранятся в браузере (localStorage).
- `api/generate.js` — серверная функция Vercel. Единственное место, где используется ключ OpenAI.
  Перед ответом она проверяет сгенерированный запрос: создаёт ваши таблицы во встроенном PostgreSQL
  ([PGlite](https://github.com/electric-sql/pglite)) и выполняет `EXPLAIN`. Если PostgreSQL вернул ошибку,
  она отправляется модели на исправление (до двух раз). Проверка ловит ошибки синтаксиса, несуществующие
  таблицы и столбцы, ошибки `GROUP BY`; смысловые ошибки она не находит.
- `samples/employees_export.xlsx` — пример файла для импорта столбцов.

## Переменные окружения (Vercel → Settings → Environment Variables)

| Имя | Зачем |
|---|---|
| `OPENAI_API_KEY` | ключ OpenAI; хранится только на сервере |
| `OPENAI_MODEL` | необязательно, по умолчанию `gpt-4o-mini` |

Пока не задан `OPENAI_API_KEY`, функция отвечает 503.

Доступа по паролю нет: любой, кто знает адрес сайта, может генерировать запросы за счёт вашего ключа. Поставьте месячный лимит расходов в настройках OpenAI.
